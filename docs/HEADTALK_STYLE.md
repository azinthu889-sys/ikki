**စာလုံး အမြင့် = ၈.၁–၁၆.၃ %H · အလယ်တန်း ၁၀.၁ %H**

⚠️ IKKI ရဲ့ `cap_pct = 0.050` (၅%H) ထက် **၂ ဆ ကြီး**သည်。
⚠️ IKKI က 「ပြောသူက ၆၄% ယူ · စာတန်းက ၇၀% ကနေ ⇒ ထပ်တင်ရန် ၅.၆%H သာ ကျန်」
   ဟု ဆုံးဖြတ်ကာ **ဖြတ်ပြောင်း** သို့ ပြောင်းခဲ့သည် (၂၀၂၆-၀၉-၂၁)。
   Reference က အဲဒီယူဆချက်ကို **ငြင်းသည်** — စာလုံးကို ပြောသူပေါ် တိုက်ရိုက်
   တင်ပြီး **အနက် အနားသတ်** နဲ့ ဖတ်စေသည်。

### နေရာချမှု
- x အလယ်မှတ် ၁၂% ကနေ ၈၆% အထိ · y ၂၀% ကနေ ၈၁% အထိ ⇒ **ဇုန် သတ်မှတ်ချက် မရှိ**
- မျက်နှာပေါ် **မတင်**ပါ — နောက်ခံ (နံရံ · မီးအိမ်ဘေး) မှာသာ
- တစ်ချိန်တည်း **၃ ခုအထိ** ပေါ်နိုင် (284s: `WHY?` ၃ ခု အရွယ်မတူ)

## ၇ · အကောင်အထည်ဖော်ချက် (၂၀၂၆-၀၉-၂၁)

စာတန်းဇုန်ကိုပါ ရှောင်သည်。

`core/planner.py` — `keyword()` က ဝါကျကနေ pop လုပ်ထိုက်သော စကားလုံး ရွေးသည်
(Latin · ဂဏန်း · `N4` ကဲ့သို့ အက္ခရာ+ဂဏန်း)。 မြန်မာစာလုံးကို **မ pop ရ** —
ဗျည်းတွဲ/သရ ပျက်မည်。

### `kinetic.word_pop` ရဲ့ တိုင်းထားသော ပြောင်းလဲမှု

⚠️ template ရဲ့ param နှစ်ခုက **ကိုယ်ထင်တာနဲ့ မတူ** — စမ်းပြီး တိုင်းထားသည် —

```
y     = စာလုံးရဲ့ အပေါ်စွန်း (အလယ်မှတ် မဟုတ်)
        ink အလယ် = y/H + k · k က size နဲ့ ကြီးသည်
        တိုင်းချက် @1080 — size 109 ⇒ k 0.104 · size 131 ⇒ k 0.140
        ⇒ k = 0.0016364·size − 0.07437      (လွဲချက် ≤ ၀.၇၅%)
size  = em box。 size 109 ⇒ ink ၈.၄%H သာ
        ⇒ ပစ်မှတ် ၁၀.၁%H အတွက် size = h × 1.20 × H
x     = param **မရှိ** ⇒ compositor က `overlay=dx:0` နဲ့ ရွှေ့သည်
```

⚠️ **အကျယ်ကို စာလုံးရေနဲ့ မှန်းဆ၍ မရ** — 「Language school」က ဘယ်အစွန်းမှာ
