၃။ `t.strip(" ကတော့မှာ")` က အက္ခရာ **အစုလိုက်** ဖြတ်သဖြင့်

   (`_drop_pre()`)。 ၂ ကြိမ် ဖမ်းမိခဲ့သည်。

### ကျန်နေသေးသည်

- ပြောသူကို **ညာဘက် မတွန်းရသေး** — reference က တွန်းသည်、ယခု ဘောင်အပြည့်
  ပေါ်မှာ ထပ်ရုံသာ ⇒ မျက်နှာနဲ့ ထပ်နိုင်သည် (panel က ၀–၄၁.၃%W)
- `plan` ထဲ မပါသေး ⇒ **UI ကနေ ပြင်လို့ မရသေး** (schema က template ID လိုသည်)
- v5 ရဲ့ အောက်ခြေ chip တန်း · ထောင့် chip မလုပ်ရသေး
