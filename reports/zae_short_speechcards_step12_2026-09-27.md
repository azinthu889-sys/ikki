# Caption ကို speech run ပေါ် တည်ဆောက်ခြင်း: ① သက်သေ · ② N အကြံပြုချက် (2026-09-27)

Code မရေးရသေးပါ။ Render လည်း မထုတ်ရသေးပါ။ ကိန်းပဲ ပါပါတယ်။

## ① Gemini word time vs cut engine speech run

**Speech run:** `core/measure.speech()`
- Cut engine ကိုယ်တိုင် သုံးတဲ့ function ပါ။ 20 ms frame · voice 300–3400 Hz ratio > 0.25 · `db > thr` (thr −33.5 dB) · 7-frame (140 ms) smoothing · hit 0.35 သုံးပါတယ်။
- `tokutei.mp4` source (voice only) ပေါ်မှာ တွက်ပါတယ်။ Output timeline ပေါ်ကို lag **−0.1437 s** (1ms waveform correlation · 12/12 ပုံသေ) နဲ့ map လုပ်ပါတယ်။
- Cut က ပထမ 1.5 s အတွင်း ရှိလို့ source ≥ 1.5 s run တွေပဲ ယူပါတယ်။

**Gemini word:** `skip.mp4` (short-916 @ 97118f6 · seed `t_s916_pin`) ရဲ့ caption ဆီ ဝင်တဲ့ `caps[].words` (cut timeline)

|---|---|---|---|---|---|---|---|
| gemini_word_start − run_start | 24 / 30 | **−0.026** | **−0.310** | **+0.373** | −0.396 | +0.434 | 21 / 24 |

(± 0.5 s အတွင်း အနီးဆုံး word နဲ့ တွဲထားပါတယ်။ + = Gemini က run ထက် နောက်ကျ)

**Speech run ပုံသဏ္ဌာန် (spec ဒီဇိုင်းကို သက်ရောက်မယ့် ကိန်း):**

| | n | median | p5 | p95 | max | spec နဲ့ ဆိုင်တာ |
|---|---|---|---|---|---|---|
| run ကြာချိန် (s) | 30 | 1.53 | 0.48 | 5.78 | 9.50 | **> 4.0 s: 4 ခု** · **< 0.6 s: 4 ခု** |
| run ကြား gap (s) | 29 | **0.08** | 0.04 | 0.264 | — | **< 0.35 s: 29 / 29** |

- gap 29 ခုလုံး 0.35 s အောက် ဖြစ်ပါတယ်။ ⇒ spec ရဲ့ "< 0.6 s run ⇒ gap < 0.35 s ဆိုရင် ပေါင်း" rule က ဒီ source မှာ **အမြဲ ပေါင်းခွင့်** ဖြစ်ပါတယ်။
- `card_off = run_end` ဆိုရင် gap ၂၉ ခုမှာ caption က **40–260 ms** ပျောက်ပြီး ပြန်ပေါ်ပါမယ် (p5 0.04 · median 0.08 · p95 0.26)။ ⇒ G6 မထိပါ။ ဒါပေမယ့် ဒါက ဇင့် "အသံ ဆုံးတာနဲ့ ချက်ချင်း ပျောက်" ဆိုတဲ့ ဆုံးဖြတ်ချက်ရဲ့ တိုက်ရိုက် ရလဒ်ပါ။ ⇒ **ဆုံးဖြတ်ရန် ကိန်း အဖြစ် တင်ပြပါတယ်**။

## နောက်တစ်ဆင့် (③) မစခင် ဆုံးဖြတ်ချက် လိုတာ

1. N = 778 px (≈ 9 cluster) လက်ခံလား။
2. Gap 40–260 ms မှာ caption ပျောက်ပြီး ပြန်ပေါ်တာ (ဗလာ flash 29 ခု/77 s) က ရည်ရွယ်ချက်အတိုင်းလား။
   - မဟုတ်ရင် "gap < X ms ဆိုရင် off ကို နောက် run ထိ ဆွဲ" rule တစ်ခု လိုပါမယ်။ ဒါပေမယ့် G2/G4 နဲ့ ဆန့်ကျင်ပါတယ်။
3. > 4.0 s run 4 ခု (max 9.5 s) ကို ခွဲမယ့် "run အတွင်း အကြီးဆုံး gap" က speech mask ထဲမှာ **မရှိပါ** (run ဆိုတာ gap မပါတဲ့ အပိုင်း)。
   - ⇒ ခွဲမှတ်ကို ဘာနဲ့ ရှာမလဲ ဆုံးဖြတ်ရပါမယ်: mask ကို ပိုသေးတဲ့ smoothing နဲ့ ထပ်တွက်မလား၊ energy dip လား၊ Gemini word boundary လား။ ဒါက G1/G2 နဲ့ ဆိုင်ပါတယ်။
