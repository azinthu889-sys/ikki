    ပြီးသွားပြီ။

    သင် အတည်ပြုရန်

    ဒါတွေကို အလိုအလျောက် မဖြတ်ပါ — ဘယ်ဟာ ပြည့်စုံလဲ စက်က မဆုံးဖြတ်နိုင်လို့ပါ။

    ပြင်ပြီး ပြန်ထုတ်မယ်

    ဒါတွေက ဗီဒီယိုထဲ ရိုက်ထည့်ထားတာမို့ ပြောင်းရင် ပြန်ထုတ်မှ ရပါမယ်။ ပြန်ထုတ်တာက အရည်အသွေး မကျပါဘူး — မူရင်းဖိုင်ကနေ ပြန်စလို့ပါ။ ပြင်ချက်အားလုံးကို တစ်ခါတည်း ပြန်ထုတ်ပါမယ်။

    စာသား ပြင်ရန်

    ဖျက်ရင် ဗီဒီယိုပါ ဖြတ်ပါမယ် — အသံပါ ပါသွားမယ်။ စာလုံး ပြင်ရင် စာတန်းပဲ ပြောင်းပါမယ် — အသံနဲ့ ဖြတ်မှတ် မထိပါဘူး (ASR မှားဖတ်တာ ပြင်ဖို့)။ ဘယ်ဟာက ဘာဖြစ်မလဲ စာကြောင်းဘေးမှာ ပြပါမယ်။

    ဗီဒီယို မဖြတ်ရသေးပါ — ဘယ်အပိုင်း ကျန်မလဲ သင် ဆုံးဖြတ်ပါ

    📝 Script Editor မှာ ဖွင့် (အသစ်)
    Script ရှိပါသလား? ဒီမှာ ထည့်ပါ

    Script ထဲ ပါတဲ့ စာပိုဒ်တွေကိုပဲ ချန်ပြီး ကျန်တာ ဖျက်ပေးပါမယ်။ စာလုံး အသစ် ထည့်လို့ မရပါ — အသံထဲ မရှိတာ ဖြတ်စရာ မရှိလို့ပါ။

    ပြန်စ ထင်ရတဲ့ အပိုင်း

    စက်က မဖြတ်ပါ — တစ်ခုချင်း ✓ ဖြတ် / ✗ မဖြတ် ရွေးပါ။ ရွေးချယ်မှုတိုင်းက app ကို ပိုတိကျအောင် သင်ပေးပါတယ်။

    ပြန်စထားတဲ့ အပိုင်း — ဘယ်တစ်ခု ချန်မလဲ

    တစ်ခုတည်းသော အကြောင်းအရာကို အကြိမ်ကြိမ် ပြောထားတာ ဖြစ်နိုင်ပါတယ်။ ချန်ချင်တဲ့ take ကို ရွေးပါ — ကျန်တာကို ဖြတ်ပါမယ်။ ပုံသေက ဘာမှ မဖျက်ပါ။

    AI အစီအစဉ်

    AI က ဖြစ်ရပ်တစ်ခုချင်းကို အကြံပြုပြီး၊ ရှိပြီးသား renderer က အဲဒါကို အကောင်အထည်ဖော်တယ်။ ဘယ်ဟာမှ မှန်းဆ မဟုတ်ဘူး — အကြောင်းရင်းနဲ့ ယုံကြည်မှု နှုန်း ပါတယ်။

    JSON ဒေါင်းမယ်

    ဗားရှင်း မှတ်တမ်း
