# **ဖြတ်ပြောင်း (cutaway)** — ပြောသူကို တကယ် ဖုံးသူ。
#
# ရင်းမြစ် ၂ ခု —
#   ① **တိုင်းချက်** (`tools/gfx_cutaway.py` · alpha အလယ်မှတ် ≥ ၀.၈၅) —
#      30 ခု。 ဤအစုက ၂၀၂၆-၀၉-၂၄ ကတည်းက အလုပ်လုပ်နေသည်。
#   ② **ကြေညာချက်** (`manifests/thm.json` ရဲ့ `role: "cutaway"`) —
#      27 ခု。 `thm.py` ရဲ့ `_cut_el()` က 「overlay အဖြစ် သုံးလျှင်
#      ပြောသူ လုံးဝ ပျောက်မည်」 ဟု ဆိုသည်。 ယခင် စာရင်းမှာ **မပါ**ခဲ့သဖြင့်
#      ဖြတ်ပြောင်း slot က တကယ့် ဖြတ်ပြောင်း မရခဲ့ပါ。
#   ⇒ ပေါင်း **57 ခု**。
#
# ⚠️ **ဤစာရင်းကို ကျယ်လွန်းအောင် မလုပ်ရ** (၂၀၂၆-၀၉-၂၅ တိုင်းချက်)。
#    တိုင်းချက် ≥၀.၈၅ ဖြစ်သူ **၁၀၂ ခု**လုံး ထည့်ကြည့်ရာ `_ff_order()` က
#    Headtop pack တစ်ခုလုံးကို inline slot ကနေ ဖယ်ပြီး ဝါကျ ၁၅ ကြောင်း
#    plan မှာ **ဂရပ်ဖစ် ၀ ခု** ဖြစ်သွားသည်。 ⇒ အလုပ်လုပ်ပြီးသား အစုနဲ့
#    ကြေညာချက်ကိုသာ ပေါင်းသည်。
#
# ⚠️ **RGB mode က တိုင်းချက် ပျက်တာ မဟုတ်** — PNG encoder က alpha အားလုံး
#    ၂၅၅ ဆိုလျှင် channel ကို ဖြုတ်ပစ်သဖြင့် ဖြစ်သည် (= အလင်းပိတ် အပြည့်)。
#    `prem5.karaoke_cap` ရဲ့ pixel က RGB (23,49,77) · alpha ၂၅၅ အားလုံး。
#    ကျွန်တော် ဒါကို 「အမှား」 ဟု မှတ်ပြီး စာရင်းကို ကြေညာချက် ၂၇ ခုသာ
#    ဖြစ်အောင် လျှော့ခဲ့ရာ **အကာအကွယ် ပျက်**ခဲ့သည် ⇒ မလုပ်ရ。
