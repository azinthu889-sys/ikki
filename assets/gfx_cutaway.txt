# **ဖြတ်ပြောင်း (cutaway)** — ပြောသူကို တကယ် ဖုံးသူ。
#
# ⚠️ ရင်းမြစ်က **template ရဲ့ ကြေညာချက်** ဖြစ်သည် — `manifests/thm.json` ရဲ့
#    `role: "cutaway"`。 `motionkit/thm.py` ရဲ့ `_cut_el()` က
#    `e["role"] = "cutaway"` ထည့်ပြီး မှတ်ချက်မှာ 「IKKI က ဒါကို ကြည့်ပြီး
#    ဖြတ်ပြောင်း လမ်းကြောင်းသို့ ပို့သည်。overlay အဖြစ် သုံးလျှင် ပြောသူ
#    လုံးဝ ပျောက်မည်」 ဟု ဆိုသည်。 ကြေညာချက်ရဲ့ `measuredBBox.area` က
#    ၀.၉၉၈၆ — ဘောင်အပြည့်。
#
# ⚠️ **alpha တိုင်းချက်ကို မယုံရ** (၂၀၂၆-၀၉-၂၅ တွေ့ခဲ့သော အမှား ၂ ချက်):
#    ① template အများစုက **RGB** (alpha channel မရှိ) render သဖြင့်
#       `convert("RGBA")` က alpha ကို ၂၅၅ ဖြည့်ပြီး ဖုံးအုပ်မှု အမြဲ
#       **၁.၀၀** ထွက်သည် — အကြောင်းအရာ မကြည့်ဘဲ。
#    ② RGBA ဖြစ်သူတွေမှာပင် `prem.lower_third` က ၈၅% အထက် ထွက်သည် —
#       lower third က ဘောင်အပြည့် မဖြစ်နိုင် ⇒ တိုင်းချက် မှားနေသည်。
#    ⇒ ယခင် စာရင်း ၃၀ ခုက **တကယ့် ဖြတ်ပြောင်း တစ်ခုမှ မပါ**ဘဲ
#      `prem5.karaoke_cap` · `word_pop_cap` · `bounce_cap` · `box_cap` ·
#      `hl_word_cap` · `line_by_line` ဆိုတဲ့ **စာတန်း** ၆ ခု ပါခဲ့သည်。
#      `_ff_order()` က အဲဒါတွေကို inline slot ကနေ ဖယ်ခဲ့သဖြင့် ဂရပ်ဖစ်
#      ရွေးစရာ လျော့ကာ ထပ်ခြင်း တိုးခဲ့သည် (Zin: 「မထပ်အောင်」)。
#
# ⚠️ `thm` သာ manifest ရှိသည် (၁၃၇ ခု — cutaway ၂၇ · board ၅ · overlay ၁၀၅)。
#    အခြား မိသားစု ~၄၇၉ ခုမှာ ကြေညာချက် **မရှိ** ⇒ overlay ဟု မှတ်သည်。
#    `board` က `measuredBBox.area` ၀.၀၀၀၈ ("frame edge") ⇒ ဖြတ်ပြောင်း မဟုတ်。
