# **Zin ကြိုက်သော SFX** — ၂၀၂၆-၀၉-၂၅ သူ တိုက်ရိုက် ပေးသော စာရင်း。
# 「ဒါငါကြိုက်တဲ့ sound effect တွေပါ။ဒီအသံတွေကိုသေချာသုံးပေးပါ။」
#
# ⚠️ `sfxpool.pick()` က ဤစာရင်းထဲက cue ကို **ဦးစားပေး** ရွေးသည် —
#    no-repeat ဝင်းဒိုးက ကုန်မှ အခြား variant သို့ ကျသည်。
# ⚠️ id ပုံစံက `<bank>/<ဖိုင်နာမည်>` (catalog id) ဖြစ်သည်。
# ⚠️ ကြာချိန် ဂိတ် (`DUR_MAX`) ကို **မလျှော့ပါ** — `dur_eff` (ကြားရသော
#    အရှည်) နဲ့ စစ်သည်。 အောက်ပါ တိုင်းချက်အရ ၄ ခု ဝင်ပြီး ၇ ခုက
#    ကြားရသော အရှည် ကိုယ်တိုင် ရှည်သဖြင့် စကားပေါ် မတင်ရ ⇒ `sting`
#    (စကား မရှိသော အခိုက်) အတွက် သီးသန့် မှတ်ထားသည်。
